Practice

01

Web and mobile, one harness

Playwright and Selenium for the browser. Appium for iOS and Android. The framework is built to scale: parallel runs, shared fixtures, and the same idea of a test on a phone and on a site.

02

Local, regional, experimental

A suite that can run on a laptop, across regions, or as an experiment. The same check can stay small while you are unsure, then run everywhere once it is trusted.

03

Visual regression

A tool that treats a layout change as a review, not a silent drift. Baselines, diffs, and a place to decide whether the picture should change.

04

AI-driven testing

Models help aim the suite: what to cover, what broke, and how to say it. The failure still has to be something a person can read and rerun.
